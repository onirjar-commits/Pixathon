# 🌀 Gravity Flip Rooms

### Flip Gravity. Outsmart Physics. Find Your Way Out.

**Gravity Flip Rooms** is a 2D puzzle game where gravity is not just a physical rule — it's a tool the player can control. Switch gravity between four directions, manipulate objects, solve challenging rooms, collect keys, and find the exit.

🎮 **Play the Live Game:** [Gravity Flip Rooms](https://onirjar-commits.github.io/Pixathon/)

---

## 💡 The Idea

What if you could change the direction of gravity whenever you wanted?

Gravity Flip Rooms explores this idea through puzzle-based gameplay. Instead of relying only on traditional movement, players must understand how changing gravity affects the character and surrounding objects.

Every gravity flip can create a new path, move an obstacle, or change the solution to a puzzle. Players must think strategically and use their limited flips wisely.

## ✨ Key Features

- **Four-Way Gravity:** Change gravity to move down, left, up, or right.
- **Gravity Preview:** Preview the upcoming gravity direction to plan your next move.
- **Interactive Physics:** Solve puzzles using movable blocks with different gravity behaviors.
- **Keys and Locked Exits:** Find the key needed to unlock the exit.
- **Limited Gravity Flips:** Make every decision count with a restricted flip budget.
- **Multiple Puzzle Rooms:** Progress through three rooms with increasing challenges.
- **Game Controls:** Pause, restart, and control sound during gameplay.
- **Distinct Visual Identity:** A dark navy and gold theme designed for a futuristic puzzle experience.

## 🕹️ How to Play

1. Start the game and explore the room.
2. Observe the obstacles and available paths.
3. Change gravity to alter how objects move.
4. Use the Gravity Preview feature to plan your next move.
5. Collect the key to unlock the exit.
6. Reach the exit to complete the room.
7. Complete all three rooms to win.

## 🎮 Controls

| Control | Action |
|---|---|
| Movement controls | Move the player |
| Gravity flip control | Change gravity direction |
| `V` | Toggle Gravity Preview |
| Pause button | Pause or resume |
| Restart button | Restart the room |
| Sound button | Toggle sound |

*Use the in-game controls and instructions to confirm the exact movement and gravity-flip key mappings.*

## 🧩 The Puzzle Mechanics

### 1. Gravity Manipulation
Gravity can change direction, requiring players to rethink movement and positioning as the environment changes.

### 2. Object Interaction
Heavy and light blocks behave differently under gravity, introducing additional strategic choices.

### 3. Resource Management
The limited number of gravity flips encourages players to plan ahead rather than repeatedly trying random directions.

### 4. Key-and-Exit Progression
Players must collect the required key before reaching the exit.

### 5. Gravity Preview
The preview mechanic supports forward planning by showing the upcoming gravity direction before a flip.

## 🚀 Run Locally

You can play the game directly through the live demo, or run it locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/onirjar-commits/Pixathon.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in a modern web browser.

The standalone HTML version does not require a separate build step.
